💡 What: Optimize `manage_marketing_campaigns` to avoid an N+1 query issue.
🎯 Why: The previous implementation queried the count of recent marketing campaigns inside an iterator. For a large number of businesses, this causes significant performance degradation.
📊 Impact: Eliminates O(N) database query roundtrips in the main marketing autonomous loop, improving overall event loop latency.
🔬 Measurement: Benchmark execution time of `manage_marketing_campaigns` over large datasets or observe the count of DB queries via logging.
