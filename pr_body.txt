🎯 Why: To reduce event loop blocking and unnecessary intermediate memory allocations from multiple generator expressions over the same collections.
📊 Impact: Reduced time complexity to O(N) and lowered memory overhead.
🔬 Measurement: Run pytest and observe execution time.
