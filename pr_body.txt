💡 What: Replaced an N+1 query loop in `Level6Agent.manage_marketing_campaigns` with a single `IN` query to pre-fetch recent campaign metadata. Removed the unused helper function `_needs_marketing_campaign`. Replaced deprecated `datetime.utcnow()` calls with `datetime.now(timezone.utc).replace(tzinfo=None)`.
🎯 Why: The previous implementation performed a `COUNT` query for every active business on every marketing loop iteration, creating an N+1 scaling bottleneck. `datetime.utcnow()` is deprecated in Python 3.12 and causes compatibility warnings/issues with SQLAlchemy logic tests.
📊 Impact: Expected to reduce autonomous marketing loop database queries from O(N) to O(1), improving throughput. Using `datetime.now(timezone.utc)` avoids Python deprecation warnings and test failures.
🔬 Measurement: Verify by executing the autonomous loop with a large set of businesses while monitoring PostgreSQL query logs, observing a reduction from N+1 statements to a single `SELECT count`.
