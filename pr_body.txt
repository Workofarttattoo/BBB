💡 What: Replaced an N+1 query vulnerability in `manage_marketing_campaigns` loop with a single grouped query using an `IN` clause to pre-fetch recent marketing campaign counts.
🎯 Why: Calling `.count()` individually on each active business during the autonomous agent loop degrades performance and blocks the event loop.
📊 Impact: Reduces database queries from O(N) to O(1) for this operation, ensuring stable long-term performance as the number of businesses scales.
🔬 Measurement: Verified functionality using mocked SQLAlchemy session queries to ensure campaigns are still generated correctly.
