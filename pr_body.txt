💡 What: Pre-fetched recent campaign IDs to resolve an N+1 query in `manage_marketing_campaigns`.
🎯 Why: The previous implementation performed a `COUNT` query for every single active business inside a loop, causing O(N) database calls. Now it performs O(1) database queries.
📊 Impact: Eliminates an N+1 query bottleneck.
