💡 What: Replaced O(N) iteration of the task queue with an O(1) set for tracking in-progress tasks.
🎯 Why: Iterating over an unbounded queue blocks the event loop under heavy load.
📊 Impact: Eliminates O(N) bottlenecks during async task assignments and executions.
🔬 Measurement: Observe lower CPU load and latency in the task event loops.
