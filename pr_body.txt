💡 What: Optimized metric gathering functions to use single O(N) loops instead of multiple sequential list comprehensions and generator expressions over the same collections.
🎯 Why: Multiple passes over collections (like customers, jobs, sessions, or businesses) using list/set comprehensions block the event loop and create unnecessary intermediate memory allocations, becoming a performance bottleneck as the data scales.
📊 Impact: Reduces intermediate memory allocations and lowers CPU overhead by consolidating calculations into a single O(N) pass, significantly improving performance for large data sets.
🔬 Measurement: Verify using the unchanged output of the demonstration scripts (`python3 src/blank_business_builder/qulab_rental_business.py` and `python3 src/blank_business_builder/magic_rd_lab.py`) and by passing the existing test suite (`pytest`).
